TWO VALUES TO UPDATE BEFORE GOING LIVE
Open config.js and replace:
1) appStoreUrl: "#" with the public App Store URL
2) supportEmail with the final FORME email address

The whole website reads those values from config.js, so each only needs to be changed once.
